UK Vehicle Check — Multi-page VS Code project

Open this folder in VS Code and launch index.html with Live Server (recommended).
Pages: Home, Free MOT Check, MOT History, MOT Report, What Is Included, FAQs, DVSA Data, Legal.

Features: shared navigation, light theme by default, persistent light/dark toggle, responsive glassmorphism cards.

Important: The live MOT lookup API is not connected. Do not present placeholder content as actual vehicle results. Configure a secure backend and authorised data source before enabling live lookups. The site is independent and not endorsed by the UK Government.
