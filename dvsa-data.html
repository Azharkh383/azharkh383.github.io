UK VEHICLE CHECK • PRACTICAL GUIDE

About DVSA MOT data

The Driver and Vehicle Standards Agency (DVSA) is responsible for the MOT testing framework in Great Britain. The official MOT history service lets the public review recorded test results for eligible vehicles.

01

What the record can contain

The official history can include test dates, expiry dates, pass/fail results, mileage readings, test numbers, failure reasons and advisory notices, subject to vehicle type and record availability.

02

Coverage varies by vehicle and region

Cars, motorcycles and vans in Great Britain generally have history from 2005; HGVs, trailers, buses and coaches from 2018. Northern Ireland uses a separate service and has records from 2017.

03

API access and this website

The MOT History API is available to authorised third-party organisations through an application process. This project has not been connected to an approved API or live data backend; no vehicle-specific result should be inferred from this page.

04

Accuracy and corrections

The record reflects information held by the official source. If a test is missing or details look wrong, contact the relevant official service or testing station; this website cannot amend DVSA records.

05

Independence and licensing

UK Vehicle Check is independent and is not a GOV.UK website, nor is it endorsed by DVSA or DVLA. When reusing public-sector information, follow the applicable Open Government Licence terms and attribution requirements.

DATA & TRANSPARENCY

How official MOT information should be used

The Driver and Vehicle Standards Agency (DVSA) administers MOT testing in Great Britain. Vehicle records should be checked against official sources before being relied upon.

Use the official record as the reference

When a date, result or mileage detail matters, verify it using the official GOV.UK MOT history service. This site is independent and does not represent the DVSA or GOV.UK.

Coverage and availability

Records shown depend on what is available from the official source for the vehicle. Do not interpret a missing result as proof that a test never took place without further verification.

Live data connection

A live lookup feature needs an authorised data source, secure server-side handling and a correctly configured backend. Browser-only code should not expose private API credentials.

Data freshness

If a site displays cached or manually entered information, it should clearly identify that limitation. Never label unverified information as live or government-verified.
